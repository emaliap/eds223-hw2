# EDS 223 HW 2: Exploring patterns of environmental justice

## Repository purpose

Contains the script **hw2.qmd** used to create maps, tables, and figures displaying the harmful lagacy of redlining in the US. 

**Research question:** 

How does a history of redlining affect a communities socioeconomic, environmental, and safety status?
